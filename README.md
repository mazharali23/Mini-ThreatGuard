# Mini AI SOC

AI-powered threat intelligence and SOC automation pipeline built using n8n, Ollama, PostgreSQL, and Telegram.

## Features

- Automated CVE ingestion
- Severity filtering
- AI-powered threat analysis
- Local LLM inference with Ollama
- PostgreSQL event persistence
- Telegram SOC alerts
- Dockerized deployment
